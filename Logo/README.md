# Laura Schnelle — Logo-Paket

Verschränktes **LS**-Monogramm (High-Contrast-Serife, Didone-Stil) + Wortmarke „LAURA SCHNELLE".

## Inhalt

### `SVG/` — skalierbar, für Web & Druck (verlustfrei, beliebig groß)
| Datei | Was |
|---|---|
| `LS-Monogramm_farbig.svg` | Nur das Zeichen — L Indigo, S Apricot (für **helle** Hintergründe) |
| `LS-Monogramm_hell.svg` | Zeichen — L Porzellan, S Apricot (für **dunkle** Hintergründe) |
| `Wortmarke_farbig.svg` | Nur der Schriftzug in Indigo |
| `Wortmarke_hell.svg` | Schriftzug in Porzellan (für dunkle Hintergründe) |
| `Logo-komplett_farbig.svg` | Zeichen **und** Schriftzug gestapelt — hell |
| `Logo-komplett_hell.svg` | Zeichen und Schriftzug gestapelt — dunkel |
| `Favicon.svg` | Zeichen im abgerundeten Indigo-Kachel (Browser-Tab / App-Icon) |

### `PNG/` — transparenter Hintergrund, hochauflösend
Dieselben Motive als PNG (freigestellt) — für Office, Social Media, schnelle Vorschauen.

## Farben
| | Hex |
|---|---|
| Tinten-Indigo | `#3A3E72` |
| Apricot | `#E0A579` |
| Porzellan (Hintergrund) | `#F5F1EA` |

## Verwendung
- **Farbig** auf hellen Flächen, **hell** auf dunklen/farbigen Flächen.
- Ausreichend Abstand lassen (mind. die Höhe des „L" ringsum), nicht verzerren, Farben nicht verändern.
- Für Web ist SVG erste Wahl (gestochen scharf, winzige Dateigröße).

## Technik / Lizenz
Die Buchstaben basieren auf **Playfair Display** (SIL Open Font License) und wurden in
**eigenständige Vektor-Pfade** umgewandelt. Das Logo braucht daher **keine Schrift-Installation**
und ist frei verwendbar — keine Font-Lizenz nötig.
